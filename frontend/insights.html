Market map: which stocks move together?

An unsupervised learning model grouped large US and Hong Kong stocks by how their weekly returns move together. Nobody told it about countries or industries.

How was this map made?

Each dot is a stock. Principal component analysis (PCA) squeezes about five years of weekly returns into a few "patterns" of movement, and the map plots each stock on two of them. Stocks close together tend to move together. The groups come from hierarchical clustering on correlation, with the number of groups chosen by the silhouette score, which measures how well-separated the groups are.

How does the model find regimes?

A Hidden Markov Model assumes the market switches between two hidden states, calm and stormy, each with its own typical daily swing. It learns those swings, and how likely the market is to switch, from the data alone (Baum–Welch algorithm). "Today" uses only past data. The shaded history uses the full sample, so it's a description of the past, not a forecast.
